# Portfólio — Ulisses Pereira Bastos

Site pessoal desenvolvido com HTML, CSS e JavaScript puro.

## Estrutura
- `index.html`: conteúdo e estrutura das seções.
- `css/style.css`: identidade visual, animações e responsividade.
- `js/script.js`: menu mobile, animações de entrada e navegação ativa.
- `imagens/perfil.svg`: ilustração provisória para a área de apresentação.

## Como abrir
Abra a pasta no Visual Studio Code e abra `index.html` no navegador. Se tiver a extensão Live Server, clique com o botão direito em `index.html` e escolha **Open with Live Server**.

## Personalização
- Troque `SEU-EMAIL@EXEMPLO.COM` no `index.html` pelo seu e-mail.
- Se quiser, substitua `imagens/perfil.svg` por uma foto sua (mantenha o nome `perfil.svg` apenas se continuar usando SVG; para foto, atualize o caminho no HTML).
- Adicione seus links de redes sociais na seção de contato quando quiser.

## Publicar no GitHub Pages
1. Crie uma conta em https://github.com/ e entre nela.
2. Clique em **New repository** e crie um repositório chamado `ulisses-portfolio`.
3. Envie todos os arquivos e pastas desta pasta para o repositório (não envie apenas o ZIP).
4. No repositório, abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/ (root)`; clique em **Save**.
7. Aguarde a publicação. O endereço normalmente será `https://SEU-USUARIO.github.io/ulisses-portfolio/`.

O GitHub Pages publica sites estáticos. Este projeto não precisa de servidor ou banco de dados.
